# Browser DevTools Notes

# Elements Panel
# What it shows
The Elements panel displays the HTML structure of a webpage along with the CSS styles applied to each element

# When to use it
- Inspect HTML elements
- View and edit CSS
- Test layout changes
- Debug styling problems

# Console Panel
# What it shows
The Console displays JavaScript output, warnings, and errors. It also allows JavaScript code to be executed interactively

# When to use it
- Run JavaScript commands
- Test variables and functions
- View error messages
- Debug application logic

# Network Panel
# What it shows
The Network panel displays every request made by the webpage, including HTML, CSS, JavaScript, images, and API calls

# When to use it
- Monitor API requests
- Inspect request and response data
- Check HTTP status codes
- Debug failed network requests

# Sources Panel
# What it shows
The Sources panel provides access to the website's source files and debugging tools

# When to use it
- Set breakpoints
- Pause JavaScript execution
- Step through code line by line
- Inspect variables during execution

# What I Learned
- How to inspect and edit HTML using the Elements panel
- How to run JavaScript and view errors in the console
- How to inspect API requests in the Network panel
- How to use breakpoints and step through JavaScript in the Sources panel
- How to DevTools helps identify and fix issues more efficiently
